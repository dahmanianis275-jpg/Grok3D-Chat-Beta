## Quick start (HTML version)

1. Download or clone this repository.
2. Open `index.html` in **Microsoft Edge** or **Chrome** (best for voice).
3. Click the microphone or type with your keyboard.

No install required for the web/HTML version.

---

## Build the Windows Setup Executable (.exe)

### Requirements
- Node.js 18+
- Windows (or cross-compile with wine if on Linux/macOS)

### Steps

```bash
# 1. Install dependencies
npm install

# 2. (Recommended) Convert icon.svg → icon.ico
#    Use any online converter or ImageMagick:
#    magick assets/icon.svg -resize 256x256 assets/icon.ico

# 3. Run in development
npm start

# 4. Build installer + portable EXE
npm run dist
```

After building you will find in the `dist/` folder:

- **Grok3D Chat Assistant Setup x.x.x.exe**  ← full NSIS installer (creates desktop + Start Menu shortcuts)
- **Grok3D-Chat-Assistant-Portable.exe**   ← single-file portable version

The Electron app points to the same `index.html` that contains the **3D face ChatGPT Assistant**.

## Features

- **3D particle background** (Three.js)
- **Animated 3D-style face** that reacts when listening / talking
- **Voice input** (microphone) via Web Speech API
- **Voice output** (TTS) — prefers Microsoft voices when available
- **Settings panel** (theme, voice on/off, rate, style) — saved locally
- **Disclaimer** always visible: this is AI software, not a human
- **No X / Twitter integration**
- **Completely free**
